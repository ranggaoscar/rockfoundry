# Agentic V1 Non-Goals

- Generate, edit, deploy, or host application source code.
- Require or provide RockFoundry accounts, login, signup, teams, comments, or multi-tenant ownership.
- Provide subscriptions, payment, SumoPod, plans, entitlements, usage credits, or managed AI billing.
- Require PostgreSQL, MinIO, Redis, cloud queues, or hosted storage.
- Import private repositories or scrape logged-in websites.
- Execute code downloaded from public references.
- Copy branding, proprietary copy, imagery, or source code from references.
- Build complex folders, tags, analytics dashboards, or a multi-step intake wizard.
