# Success Metrics

Measure after the first public cohort, not before.

| Metric | MVP target | Definition |
|---|---:|---|
| Activation | 50% | New projects that complete first interview round |
| Export completion | 30% | Activated projects that download ZIP within 7 days |
| Build readiness | 60% | Exported projects marked MVP Ready |
| Paid conversion | 5% | Cloud Starter purchases / eligible visitors |
| Payment integrity | 100% | Successful payments with exactly one active term |
| Generic-question rate | <5% | Reviewed questions that pass the generic-question failure test |

Instrument events without storing raw private prompts in analytics.
