# RockFoundry Win Wedge

Status: **locked for next 30 days**  
Date: 2026-08-18

## One-sentence win thesis

RockFoundry wins by becoming the **pre-coding decision system** that makes coding agents invent fewer product decisions — not by writing prettier PRDs.

## Category we own

**Agentic Product Discovery**

Not:

- PRD generator
- coding agent
- project-management SaaS
- generic chatbot wrapper

## Primary wedge (narrow on purpose)

| Field | Lock |
| --- | --- |
| Persona | Indie builder / vibe coder who already uses Claude Code, Codex, Cursor, or similar |
| Job | Turn a multi-entity business idea into a coding-agent-safe handoff |
| Beachhead domain | **Multi-brand / multi-unit CRM & ops** (sales + customer identity + permissions) |
| Supporting domains | Multi-branch rental, multi-warehouse inventory (secondary demos only) |
| Killer moment | User says: **"Oh, I hadn't thought of that."** within the first 3 questions |
| Primary artifact | Anti-invention handoff package, not just BRD/PRD/ERD |
| Distribution wedge | Local-first + open-source + BYOK trust for private ideas |

## Why this wedge wins

1. Multi-brand CRM is full of hidden decisions coding agents invent silently.
2. The failure mode is expensive and recognizable (wrong ownership, wrong permissions, dirty customer data).
3. RockFoundry already has domain packs for CRM / rental / inventory — do not dilute into 20 shallow industries yet.
4. The competitive surface (chat + markdown) looks similar; the **Decision Debt + handoff contract** does not.

## What “different but winning” means

| Surface (looks similar) | Moat (actually wins) |
| --- | --- |
| Chat interview | Unknown-unknown discovery with domain risk weights |
| BRD / PRD / ERD | Canonical state + provenance + readiness by risk |
| Export zip | `DO_NOT_INVENT.md` + decisions + invariants coding agents must obey |
| “AI PM” claims | Measurable reduction in invented product behavior |

## Positioning hierarchy

1. **Principle:** Before AI writes your code, make sure it isn't inventing your product.
2. **Promise:** Find the missing decisions before they become bad code.
3. **Category line:** Open-source agentic product discovery for AI builders.
4. **Wedge line:** Stop coding agents from inventing your CRM decisions.

## Success metrics (wedge)

| Metric | Target (30 days) | Definition |
| --- | --- | --- |
| Magic-moment rate | ≥ 70% of pilot sessions | User encounters at least one non-obvious high-risk decision in first 3 questions |
| Decision capture rate | ≥ 80% answered high-risk topics become accepted decisions | Not just chat text |
| Handoff completeness | 100% exports include BRD/PRD/ERD + DO_NOT_INVENT + DECISIONS + READINESS | Deterministic package |
| Invention-risk clarity | 100% projects show Decision Debt score + top risks in UI | Visible without opening docs |
| Coding-agent follow-up drop | Qualitative win in 5 side-by-side trials | Same idea with vs without RockFoundry handoff |
| Domain precision | CRM pack questions reference brand/sales/customer nouns | No generic “do you need auth?” filler |

Avoid vanity metrics: pageviews, fancy dashboards, template count, “AI features shipped”.

## Non-goals during wedge

- Accounts, teams, billing, hosted SaaS
- Becoming a coding agent
- Broad industry template marketplace
- Pixel-perfect marketing site before magic moment is reliable
- Native Anthropic/Gemini adapters before handoff quality is proven
