# Implementation Plan

Build a vertical slice before broadening the product.

## Phase 1 — Local discovery package

Create project state, idea extraction, one adaptive interview round, decision log, readiness calculation, and deterministic ZIP export. Use a mock AI adapter in development. This proves the core value without billing or reference fetches.

## Phase 2 — References and account persistence

Add authenticated projects, asynchronous public URL/repo analysis, bounded fetch security, and project resume. Keep references advisory.

## Phase 3 — Cloud Starter

Add managed AI gateway, usage guardrails, SumoPod QRIS adapter, verified webhook entitlement, 30-day history policy, and billing UI.

## Phase 4 — Release hardening

Run security review, accessibility checks, error-path tests, backup/restore rehearsal, legal/privacy review, and pilot launch with 10 builders.

Do not start Phase 3 until an exported Phase 1 package can drive a real small app build.
