# Security

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ranggaoscar/rockfoundry/security/advisories/new).
Do not open a public issue, and never include real hostnames, IP addresses, keys or tokens.

Rock Foundry treats every scanned repository as untrusted. See [docs/safety.md](docs/safety.md) for
exactly what it runs, reads, masks and writes.
