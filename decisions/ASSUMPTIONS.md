# Assumptions

- The first supported output is an agent-ready Markdown package for a web application project.
- The MVP has one owner per workspace and does not require team collaboration.
- Self-hosted users can configure a compatible provider key and storage/database environment.
- Cloud Starter limits are five active projects, three completed exports per term, three URLs, one public repo, and 30-day history.
- The selected auth, database, storage, and model vendors will be chosen during implementation without changing the product contract.
- Managed AI is subject to fair-use/budget controls and fallback to BYOK.
