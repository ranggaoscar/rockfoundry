# User Flows

## Discovery to export

```text
Idea intake → profile + assumptions → interview round → state update
                                     ↘ contradiction review ↗
Reference add → analysis ────────────────────────────→ readiness → export ZIP
```

The builder may export at any level. The export must state the achieved level and unresolved blockers.

## Payment

```text
Select Cloud Starter → create pending invoice → show QRIS → verified webhook
→ idempotently activate 30-day entitlement → receipt and billing history
```

Browser return is informational only; the webhook determines activation.
