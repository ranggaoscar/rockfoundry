# Reference Analysis

References guide patterns, not copying. The system stores source URL, fetch timestamp, access result, license where available, observations, and limits.

## URL analysis

For an accessible public page, extract information architecture, navigation labels, interaction patterns, density, responsive cues, status-display patterns, and general visual direction. Do not reuse exact copy, logos, illustrations, or unique brand identity.

## Public repository analysis

Record language, framework, folder conventions, auth/data patterns, deployment signals, dependency licenses, and repository license. Report incompatible or missing licenses as a caution. Do not copy code into the exported package.

## Failure behavior

If a URL blocks access, is paywalled, or times out, retain the reference with `analysisStatus: unavailable`, explain the reason, and continue discovery. A failed reference never blocks project export.
