# Information Architecture

```text
App
├── Projects
│   ├── Overview
│   ├── Interview
│   ├── References
│   ├── Decisions
│   ├── Readiness
│   └── Export
├── Billing (Cloud only)
└── Settings
    ├── Profile
    ├── AI provider / BYOK
    └── Data and deletion
```

Project state is available from every project page. The Interview is the default route until the project reaches Prototype Ready.
