# RockFoundry Agentic V1 Screen Inventory

| Surface                | Purpose                                    | Primary actions                                                       |
| ---------------------- | ------------------------------------------ | --------------------------------------------------------------------- |
| Workspace empty state  | Start a project with almost no explanation | Describe idea, choose example                                         |
| Workspace conversation | Discover the product through chat          | Send message, answer inline option, paste URL, retry, stop generation |
| Project sidebar        | Switch or start projects                   | New project, open recent project, search long list                    |
| Project header         | Keep orientation without clutter           | Open readiness, documents, overflow actions                           |
| Context drawer         | Inspect secondary project knowledge        | Review readiness, decisions, assumptions, contradictions, references  |
| Documents view         | Preview generated build specifications     | Open BRD/PRD/ERD, regenerate, copy, download                          |
| Provider settings      | Configure BYOK only when needed            | Select provider, base URL, API key, model, test connection            |
| Error state            | Recover without technical leakage          | Retry provider/tool call, open settings                               |

## Explicitly removed from V1

- pricing;
- subscription and billing;
- login, signup, account, and session screens;
- permanent analytics dashboard;
- multi-step idea intake wizard;
- separate interview tab as the primary workflow;
- complex project folders and tags.
