# Screen Inventory

| Screen | Purpose | MVP actions |
|---|---|---|
| Project list | Resume work | Create, open, delete project |
| Idea intake | Establish context | Submit idea, target readiness |
| Interview | Resolve highest-risk decisions | Choose, explain, skip with reason |
| References | Add evidence | Add/remove URL or public repo; view analysis |
| Decisions | Preserve traceability | Review accepted assumptions and conflicts |
| Readiness | Explain gaps | View category score and blockers |
| Export | Hand off to agent | Render, download ZIP |
| Billing | Maintain Cloud access | Create invoice, view status |
| Settings | Provider and account control | Set BYOK, delete account/project |
